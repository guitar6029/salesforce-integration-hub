# Salesforce Integration Hub

A Node.js and TypeScript project exploring reliable integrations between partner systems and Salesforce CRM.

## Goals

- Integrate with Salesforce using its REST API and OAuth.
- Validate and map incoming partner referrals.
- Handle retries, idempotency, and rate limits.
- Track processing outcomes and reconcile failures.

## Technology

- Node.js
- TypeScript
- Salesforce REST API
- GitHub Actions
